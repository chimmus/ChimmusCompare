# ChimmusCompare

Stock comparisons!

- Type out a symbol to get a candle stick graph about it!
- Type 2 symbols (with a space seperating them) to get a candle stick graph about both!
- Compare 2 symbols and figure out which one has risen the most!
- Shows the last 7 days of data
- All in the terminal!
